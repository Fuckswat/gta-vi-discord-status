## Как запустить

1. Открой Discord на Windows и убедись, что в настройках включена публикация игровой активности.
2. Скачай [GTA-VI-PC-Edition.bat](https://github.com/Fuckswat/gta-vi-discord-status/releases/download/v1.0.0/GTA-VI-PC-Edition.bat) и запусти его.
3. В профиле появится **Grand Theft Auto VI** с обложкой, строкой **PC Edition** и таймером. Чтобы убрать статус, запусти тот же батник ещё раз.

При запуске на пару секунд появится консоль. Пока статус работает, у помощника нет окна и иконки в трее. Всё помещается в один батник. Он собирает локальный помощник средствами Windows и подключает его к открытому Discord через Rich Presence. Токен или пароль не нужны.

Это фанатский прикол для профиля Discord. Игры в батнике нет.
